# KingbaseES V9R1 MySQL 兼容模式初始化脚本

本目录由 `APIJSON-Demo/MySQL` 机械转换生成。原目录中的
每个 SQL 文件都有同路径对应文件；插入数据的实际值保持不变，MySQL
反斜杠转义会转换成标准 SQL 字符串写法，超大单条 `INSERT` 仅按 200 行拆批，
便于在 KStudio 中执行。

## 推荐导入

在 KStudio 中连接 MySQL 兼容模式的 `apijson` 数据库，选择 `public` 模式，
打开并执行 `import.sql`。

`import.sql` 采用以下规则：

1. 以 MySQL 根目录的 `sys.sql` 作为共同表的数据快照。
2. 从 `single/Auto/UIGO` 补入主脚本不存在的 `Device`、`Flow`、`Input`、
   `Output`、`System`。
3. 最后创建 `ViewTable`。
4. 不再次执行其他同名表的 `single` 文件，因为它们与 `sys.sql` 来自不同
   时间的数据快照，会覆盖主脚本中的数据。

## 校验

数据库导入完成后执行 `verify.sql`；22 张表返回的 `status` 均应为 `OK`，
并且最后一项应显示 `ViewTable` 为视图。

## 语法转换

- `bigint(20)`、`int(11)` 等 MySQL 显示宽度转换为标准整数类型。
- `tinyint` 转换为 `smallint`，`longtext` 转换为 `text`。
- `double` 转换为 `double precision`。
- `AUTO_INCREMENT` 转换为 `GENERATED BY DEFAULT AS IDENTITY`，并保留原始
  起始值。
- MySQL 表选项、转储版本指令和 `LOCK TABLES` 被移除。
- `KEY`/`UNIQUE KEY` 转换为 KingbaseES 可执行的索引/约束语法。
- 标识符继续使用反引号，以符合 KingbaseES MySQL 兼容模式及 APIJSON
  `KINGBASE-MYSQL` 方言。
